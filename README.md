# Análise de Vendas com Geração de Gráficos

Projeto desenvolvido em Python com foco em análise exploratória de dados de vendas e geração de gráficos para visualização de métricas e informações comerciais.

## Sobre o Projeto

Este projeto foi criado com o objetivo de praticar análise de dados, manipulação de informações e visualização gráfica utilizando Python.

A análise é realizada a partir de um conjunto de dados de vendas, permitindo explorar métricas e gerar gráficos para melhor interpretação dos resultados.

No notebook analise_exploratoria.ipynb foram criados alguns gráficos para entender melhor os dados de vendas:

Distribuição do Faturamento: mostra em um histograma como os valores de faturamento estão distribuídos. Assim, é possível ver se a maioria das vendas tem valores baixos ou se existem muitos pedidos de alto valor.

Faturamento por Região: compara, através de um gráfico de barras, o desempenho das diferentes regiões. Isso ajuda a identificar quais regiões contribuem mais para as vendas.

## Como Executar


```bash

```
